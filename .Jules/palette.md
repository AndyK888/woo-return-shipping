## 2024-05-25 - Redundant ARIA Labels vs Semantic HTML
**Learning:** Adding `aria-label`s to inputs that already have adjacent visible labels (even if unlinked) can be an anti-pattern, as screen readers prioritize `aria-label` overriding visible text. Furthermore, using class methods like `this.escapeHtml` inside string templates for JS UI rendering can cause TypeErrors due to lost context. Adding `aria-live="polite"` and `role="alert"` to dynamically rendered error `div`s is a safer, more robust accessibility enhancement.
**Action:** Avoid adding `aria-label` to inputs when visible labels are nearby; instead prefer `for`/`id` linking. For dynamic validation errors in JS apps without frameworks, always use `aria-live` and `role="alert"` to ensure screen readers announce them.

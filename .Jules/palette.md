## 2024-05-24 - Accessibility for dynamic and server-rendered refund fee inputs
**Learning:** For inputs with dynamic labels based on WooCommerce settings, it's crucial to explicitly map these custom labels (e.g. "Retail Box Damage") to `aria-label` attributes to ensure screen readers provide context. In hybrid JS/PHP setups, this needs to be maintained in both the JS template (`admin-refund.js`) and the PHP fallback (`class-wrs-admin.php`). Also, decorative currency symbols like `-$` should be marked with `aria-hidden="true"` to prevent redundant/confusing announcements.
**Action:** Always verify that dynamically injected UI components with user-configured labels construct proper `aria-label`s, and ensure decorative currency or math symbols adjacent to inputs are hidden from assistive technology. Replicate these fixes in the server-side templates as well.

## 2025-06-05 - Enhance screen reader support for dynamically updating refund totals and form inputs
**Learning:** Found that dynamically updated refund totals (like gross refund, total deductions, and net to customer) were not being announced to screen readers. Adding `aria-live="polite"` directly to the container holding these recalculating values correctly announces changes without interrupting the user. Additionally, inputs rendered inside dynamically generated JS elements (or server-rendered fallback) were missing explicitly associated visible or visually hidden (`.screen-reader-text`) `<label>`s, and explicitly setting `for="id"` on adjacent labels fixes form accessibility. Applying `role="alert"` ensures dynamic validation messages are instantly announced.
**Action:** Always wrap recalculating financial totals in `aria-live="polite"` regions, apply `role="alert"` to dynamically shown validation containers, and explicitly associate explicitly visible `<label for="...">` associations or visually hidden `.screen-reader-text` labels for form inputs inside dynamically generated HTML.

## 2024-05-24 - Optimizing the woocommerce_order_get_items hook
**Learning:** The `woocommerce_order_get_items` hook is executed very frequently because WooCommerce retrieves order items repeatedly (for instance, when building summaries, tax lists, checkout steps, or email generation). When filtering items (such as hiding specific fees), iterating through all items with expensive type checks (`instanceof WC_Order_Item_Fee`) can become a performance bottleneck.
**Action:** When filtering order items via `woocommerce_order_get_items`, use the 3rd parameter `$types` which indicates the item types WooCommerce is requesting. Implementing an early return (e.g., `if (!in_array('fee', $types, true)) { return $items; }`) prevents O(N) array iteration for queries that don't even include the target type.
